## 1. 背景与目标

### 1.1 背景

个人拥有的账号与密码越来越多，普遍痛点包括：

- 密码数量大、难以记住，容易遗忘或反复重置；
- 为便于记忆而重复使用同一密码，安全风险高；
- 将密码明文记录在便签、备忘录、聊天记录中，有泄露风险；
- 缺乏统一的分类、检索与备份手段，设备更换或丢失时数据难以找回。

### 1.2 目标

构建一款**移动端、Android、供个人使用、本地化管理的密码管理 App**，实现：

1. 密码等敏感信息统一、结构化地保存在**设备本地**（不上传云端）；
2. 通过**主密码 + 生物识别**保护访问，防止他人查看；
3. 支持密码条目的增删改查、分类/标签/搜索；
4. 支持**动态验证码（TOTP）**、密码生成器、自动填充等提效能力；
5. 支持**加密导出 / 导入 / 备份**，降低设备丢失导致的数据损失风险；
6. 忘记主密码时可凭**密保问题**重置主密码（原主密码本身不可取回）。

### 1.3 非目标（范围外）

以下内容**不在**本期范围内（如后续需要，另行立项）：

- 云同步 / 多设备同步；
- 多用户、团队共享、家庭订阅、协作权限；
- iOS、浏览器插件 / 桌面端；
- 界面多语言国际化（本期仅中文）；
- 证件、银行卡等非账号类档案条目（本期仅「账号密码 + TOTP」）；
- 密码安全巡检、暗网泄露检测等增值服务。

### 1.5 核心操作流程（2026-09-24 补充）

> 来源：设计稿配套的流程说明。其中 3 处描述与已定需求冲突，已按 §13.0 的 C8–C10 修正，
> **修正处已标注**，未标注的段落为原样采纳。

**解锁与导航**

1. 启动后进入解锁页（**必须校验主密码**——原型演示用的「任意密码即可进入」不采纳，见 C8）。
2. 输入主密码解锁；已启用生物识别时，页面上同时提供「指纹 / 面容解锁」入口。
3. 底部四个标签页（密码 / 生成 / 安全 / 设置）一键切换，选中态跟随点击。
4. 在密码标签点击条目进入详情页；**系统返回键遵循页面栈**（详情 → 列表 → 退出）。

**列表与搜索**

1. 密码列表展示条目图标、名称与副标题，标题下显示条目总数。
2. 支持分类筛选 chips（全部 / 收藏 / 各分类）与关键词搜索。
3. 右下角悬浮「＋」按钮快速新建条目；**条目增删改后列表实时更新**（见 FR-18）。
4. 列表页右上角锁图标快速锁定。

**详情与编辑**

1. 详情页展示用户名、密码（掩码，可切换明文）、网址与备注，支持复制与收藏。
2. 详情页**不展示 TOTP 验证码**——TOTP 属二期（见 C9）；存储层已预留密钥字段。
3. 编辑页可修改全部字段（含分类与标签），保存后立即生效。
4. 删除需二次确认，确认后条目不可恢复（无回收站）。

**生成器与安全中心**

1. 生成器调节长度、选择字符类型，实时生成密码并显示**强度评级与强度条**；
   支持「重新生成」与「复制密码」。
2. 安全中心以卡片展示**总密码数、弱密码数、重复使用数、长期未更新数**
   （**不含泄露数量**——不做联网检测，见 C10），并提供「去修改」快捷入口。

## 2. 术语与范围

| 术语 | 定义 |
|---|---|
| 密码条目 | 一条被管理的账号/凭据记录，含标题、用户名、密码、网址、备注等字段 |
| 主密码 | 用户设置的唯一解锁口令，是整个本地密码库的访问密钥 |
| 密保问题 | 用户设置的一组（3 道）问答，用于忘记主密码时验证身份并重置主密码 |
| 生物识别 | 指纹 / 面容等设备能力，用于在主密码基础上快速解锁 |
| TOTP | 基于时间的一次性动态验证码，用于双重验证，30 秒滚动 |
| 本地存储 | 数据仅加密保存在设备本机，不经过任何网络上传 |
| 加密备份 | 可将本地数据导出为受口令保护的加密文件，用于迁移/恢复 |
| 自动填充 | 在登录表单处自动填入用户名/密码 |
| 锁定态 | App 被锁定、需再次认证才能查看内容的受保护状态 |
| 剪贴板 | 系统剪贴板，用于临时承载复制的密码/用户名/动态码 |

**用户画像**：单一自然人用户，使用 Android 设备，自行维护自己的密码库，不与他人共享。

## 5. 场景枚举

### 5.1 FR-1 首次启动与初始化

**正向场景**
- S1：全新安装后首次打开，展示引导；用户设置主密码并二次确认一致，密码库创建成功，进入主界面（空库）。
- S2：主密码不满足强度要求时，界面给出提示；用户补强后设置成功。
- S2b：用户按引导设置 3 道密保问题及答案，初始化完成后可在忘记密码时使用找回。

**负向场景**
- S3：两次输入主密码不一致，提示「两次输入不一致」并阻止进入。
- S4：用户跳过 / 拒绝设置主密码，提示无法在未设置主密码前使用，返回设置流程。

**异常场景**
- S5：设置中途杀进程，下次打开仍在「未初始化」状态，需重新设置（无脏数据）。

**边界条件**
- S7：主密码长度 8 / 64（最小/最大）均按规则校验（见 §6）。
- S8：主密码含全角、空格、emoji 等可见字符应可接受；仅拒绝不可见控制字符与首尾纯空白。

### 5.2 FR-2 解锁与认证

**正向场景**
- S9：已设主密码后，输入正确主密码解锁，进入密码列表。
- S10：已启用生物识别，出现生物识别并通过后直接解锁。

**负向场景**
- S11：输入错误主密码，提示「主密码错误」，不进入且密码库不被破坏。
- S12：连续错误 5 次，锁定 1 分钟，期间提示剩余等待时间。

**异常场景**
- S13：生物识别临时不可用（如系统未授权、传感器异常）或连续失败，自动降级为「请输入主密码」。
- S14：用户在系统层禁用/撤销生物识别授权，App 下次仅保留主密码解锁并提示。

**边界条件**
- S15：锁定后立刻再次进入，应仍处于锁定态、需重新认证。
- S16：生物识别与主密码交叉失败，不应出现绕过主密码的路径。

### 5.3 FR-3 密码条目 CRUD

**正向场景**
- S17：填写标题 + 密码（及可选字段）保存，条目进入列表并可检索到。
- S18：编辑条目后保存，字段更新成功且历史信息被新值覆盖。

**负向场景**
- S19：必填字段缺失或非法（标题空白、用户名为空、密码为空、网址非法等），阻止保存并高亮提示。
- S20：删除条目时需二次确认；取消则不删除。

**异常场景**
- S21：编辑过程中锁定/切后台导致页面失效，重新解锁后未保存的修改丢失（需提示保存状态）。
- S22：存储读写异常（如空间不足）导致保存失败，给出错误提示，不产生半条数据。

**边界条件**
- S23：各字段长度取最大边界值（见 §6）。
- S24：空库（0 条）与大量条目（接近 5000 条上限）时列表与搜索表现正常。
- S25：标题/用户名/备注包含特殊字符、换行、emoji 时可正确保存与展示。

### 5.4 FR-4 密码生成器

**正向场景**
- S26：选择长度与字符集生成密码，结果满足所选规则，可复制/填入。

**负向场景**
- S27：未勾选任何字符集时生成，提示至少选择一种字符集。
- S28：长度输入超出 4–32 范围，提示并纠正。

**异常场景**
- S29：生成依赖的随机源不可用时，退避并提示重试。

**边界条件**
- S30：长度 4 与 32 均能生成，勾选「排除易混淆字符」时结果不含 0/O、1/l/I。

### 5.5 FR-5 分类/标签/搜索

**正向场景**
- S31：为条目指定分类/标签后，可按键过滤；关键字命中标题/用户名/网址并快速定位。
- S32：搜索无结果时显示空态，不报错。

**负向场景**
- S33：分类/标签名非法（超长、空白）被拦截。

**异常场景**
- S35：分类/标签删除后，原有条目回退为「未分类」而非丢失。

**边界条件**
- S36：单条目标签数量上限 20 个、标签名长度 1–30（见 §6）。
- S37：大量条目下搜索结果滚动性能正常（见 §9）。

### 5.6 FR-6 自动填充

**正向场景**
- S38：在已关联的目标站点/App 表单处触发自动填充（系统级 Android 自动填充），正确填入用户名与密码。

**负向场景**
- S39：无可匹配条目时，提示无匹配项而不填入。

**异常场景**
- S40：目标表单字段非标准、无法识别时，优雅降级为手动复制，不崩溃。

**边界条件**
- S41：同一网站存在多条候选记录时，提供选择而非盲目填充第一个。

### 5.7 FR-7 导入/导出/备份

**正向场景**
- S42：导出时使用**当前主密码**生成加密备份文件；在新设备导入并输入同一主密码后，条目完整恢复。
  （v1.3.0 决策：备份密钥由主密码派生，**不设独立备份口令**。）
- S43：导入前先做预检，向用户展示该备份的**条目数**；用户确认后**整库替换**
  （清空 + 写入），不是合并、不是去重。
- S44：备份文件包含全部条目与全部分类，不含密保问题与答案。

**负向场景**
- S45：导入时主密码错误或文件损坏，提示失败且不污染现有数据。
- S46：备份内容不合规（某条记录缺必填项、引用了备份里没有的分类、条数超过 5000）时，
  **整体拒绝**并说明原因，密码库保持原样。
- S49：改主密码或用密保问题重置主密码后，此前导出的备份**永久无法解开**——
  界面必须在导出/导入页把这一后果写在明处。

**异常场景**
- S47：导出过程中断（存储不足/中断），不产生看似成功实则损坏的备份文件。

**边界条件**
- S48：空库导出、接近 5000 条上限的大数据集导出均能完成或明确提示。

### 5.12 FR-10 关于与安全提示（v2.0.0 补全本节）

## 6. 输入限制与数据校验规则

### 6.1 主密码

| 规则项 | 约束 |
|---|---|
| 最小长度 | 8 |
| 最大长度 | 64 |
| 强度要求 | 至少含两类字符（大写/小写字母、数字、符号任两类） |
| 一致性 | 设置/重置时二次输入必须完全一致 |
| 字符范围 | 允许任意可见字符（含全角、emoji、空格）；拒绝不可见控制字符与首尾纯空白 |

### 6.2 密保问题

| 规则项 | 约束 |
|---|---|
| 题目数量 | 3 道，均为必答 |
| 题目长度 | 1–100 字符，非空白 |
| 答案长度 | 1–60 字符 |
| 答案存储 | 与主密码同等加密存本地，禁明文 |
| 匹配规则 | 精确匹配，去除首尾空白后比对（大小写敏感） |
| 修改时机 | 已解锁态下可修改，需先验证当前主密码 |

### 6.3 密码条目字段

| 字段 | 必填 | 长度 / 约束 | 校验规则 |
|---|---|---|---|
| 标题 title | 是 | 1–100 字符 | 去除首尾空白后非空 |
| 用户名 username | 是 | 1–255 字符 | 必填非空（v0.12 起；此前允许为空） |
| 密码 password | 是 | 1–255 字符 | 必填非空，支持任意可见字符含符号 |
| 网址 url | 否 | 0–2048 字符 | 若填写需符合 URL 规范（宽松校验，非法则提示） |
| 备注 notes | 否 | 0–2000 字符 | 任意文本 |
| 分类 category | 否 | 单个预置/自定义分类 | 名称 1–30 字符、非空白 |
| 条目类型 type | 否 | 枚举：账号 / 银行卡 / WiFi / 证件 | 默认「账号」；非法值拒绝保存；v0.11 起无 UI 入口，新建默认「账号」；列仍在库中，列表副标题的渲染方式仍依赖它 |
| 收藏 favorite | 否 | 布尔 | 默认否；与主密码无关的普通字段 |
| TOTP 密钥 secret | 否 | Base32 格式 | 非法格式拒绝保存 |

> 通用规则：所有文本字段去除首尾空白后校验；长度按「Unicode 码点」计数。

### 6.4 密码生成器参数

| 参数 | 范围 / 默认 |
|---|---|
| 长度 | 4–32，默认 16 |
| 字符集 | 大写、小写、数字、符号，至少勾选一类 |
| 排除易混淆字符 | 可选（0/O、1/l/I 等） |
| 强度评级 | 由长度与字符类数推导：弱 / 中 / 强 / 非常强 |
| 默认长度 | 取自设置项「默认密码长度」（4–32，默认 16） |

### 6.5 搜索 / 分类 / 标签

- 搜索关键字：0–100 字符，大小写不敏感，自动去除首尾空格；命中范围含标题、用户名、网址、标签、分类名。
- 分类：名称 1–30 字符、非空白；**单选**；删除分类后其下条目回退为「未分类」，不删除条目。
- 标签：见 6.3，多选，去重。
- 收藏：布尔；筛选 chips「收藏」与「全部」互斥。
- 列表筛选维度：全部 / 收藏 / 各分类，单选一档。

### 6.6 安全中心判定口径

> 全部为**本地离线**计算，不发起任何网络请求、不申请 INTERNET 权限。

| 指标 | 判定规则 |
|---|---|
| 总密码数 | 条目总数 |
| 弱密码 | 复用 §6.1 主密码强度规则判定（<8 位 / 单一字符类 / 纯空白 / 含控制字符） |
| 重复使用 | 同一密码库内明文比对；**须在解锁会话内短暂解密，比对结束立即清零中间明文** |
| 长期未更新 | 条目 `更新时间` 距今超过 180 天 |
| 泄露检测 | **不实现**（需联网，与「纯本地、无网络请求」冲突）——见 §13 决策 C2 |

## 8. 业务规则与约束

- BR-1：**单一主密码**，一个密码库对应一个主密码，不提供多份密码库。
- BR-2：**本地优先**：密码数据在本地加密存储，不主动上传网络；无云同步。
- BR-3：**个人使用、仅本地存储、无需登录**：不涉及账号体系、多用户、权限分级，无第三方账号登录、不预留登录接口。
- BR-4：**备份加密**：所有导出备份须受口令保护（默认主密码，可另设独立口令），禁止导出明文密码库。
- BR-5：**删除不可撤销**：删除条目需二次确认，删除后永久删除（无回收站、不可恢复）。
- BR-6：**忘记主密码**：凭 3 道密保问题全部答对可重置新主密码；原主密码本身不可取回。
- BR-7：**自动锁定优先于便利**：凡锁定态，任何快捷入口（复制、填充、最近记录预览）一律禁用。
- BR-8：**剪贴板自动清理**：复制敏感信息后 30 秒清空剪贴板。
- BR-9：**错误限流**：连续输错主密码 5 次，锁定 1 分钟；密保找回路径与主密码**共享同一限流计数**（v0.5 扩展，堵 R7 密保爆破缺口）。
- BR-10：**单平台**：本期仅支持 Android；系统能力以 Android 为准。

## 9. 非功能需求

### 9.1 性能

- NFR-P1：条目列表在 1000 条规模下滚动流畅，搜索响应 < 500ms；5000 条上限内不出现明显卡顿。
- NFR-P2：解锁（主密码或生物识别）在正常设备上 < 1s 完成。
- NFR-P3：导入/导出在 1000 条规模下 30s 内完成（上限 5000 条时给出进度反馈）。

### 9.2 安全

- NFR-S1：**静置数据加密**：密码库在本地必须以加密形式保存，不得明文落盘。
- NFR-S2：主密码不以明文存储，仅以单向派生/校验方式保存（不指定具体算法）。
- NFR-S3：除认证与填充外，敏感明文不出现在运行时日志；日志一律脱敏。
- NFR-S4：锁定后内存中的明文应尽快清除；切换后台时禁止明文出现在系统任务预览/截图（尽力而为，受系统能力约束）。
- NFR-S5：备份文件必须口令加密；备份口令不得与备份文件一同存储。
- NFR-S6：检测到越狱/root 设备时给出风险提示，不阻止使用。
- NFR-S7：密保问题答案与 TOTP 密钥与其他敏感字段同等加密存储。

### 9.3 合规

- NFR-C1：个人自用、纯本地存储，暂不涉及数据出境、GDPR 等跨境合规；若未来加入云同步需重新评估。
- NFR-C2：不上传用户数据，隐私政策须明确「数据仅存本机、不收集、不联网上传」。
- NFR-C3：生物识别仅调用系统 API，App 自身不存储生物特征原始数据。

### 9.4 可用性

- NFR-U1：首次使用引导 ≤ 3 步即可完成主密码与密保问题设置并进入主界面。
- NFR-U2：常用操作（新增条目、搜索、复制密码）≤ 3 次点按可达。
- NFR-U3：错误提示明确、可操作（指明缺什么、如何修正），非技术黑话。
- NFR-U4：支持主流 Android 版本；最低系统版本由开发评估确定（业务不设约束）。

## 10. 验收标准（Gherkin）

### 10.1 首次启动与初始化（FR-1）

```gherkin
场景：首次启动设置主密码成功
  假设 用户首次打开未初始化的 App
  当 用户输入主密码并再次输入一致的确认密码，且满足强度要求
  那么 系统创建密码库并进入主界面，主密码设置完成

场景：两次主密码不一致
  假设 用户处于主密码设置流程
  当 用户两次输入的密码不一致
  那么 系统提示「两次输入不一致」且不进入主界面

场景：主密码强度不足
  假设 用户处于主密码设置流程
  当 用户输入的密码短于 8 位或仅含一类字符
  那么 系统提示具体强度要求并阻止提交

场景：设置密保问题
  假设 用户已完成主密码设置
  当 用户录入 3 道密保问题及答案并提交
  那么 系统保存密保信息，初始化完成
```

### 10.2 解锁与认证（FR-2）

```gherkin
场景：主密码正确解锁
  假设 密码库已初始化且处于锁定态
  当 用户输入正确主密码
  那么 系统解锁并展示密码条目列表

场景：主密码错误
  假设 密码库已初始化且处于锁定态
  当 用户输入错误主密码
  那么 系统提示「主密码错误」，保持锁定态

场景：连续错误触发限流
  假设 密码库已初始化且处于锁定态
```

## 12. 权限与安全

- **认证**：主密码为唯一根凭证；生物识别作为快速解锁的辅助，不替代主密码。
- **找回**：密保问题（3 道全对）仅用于重置主密码，不通取回原主密码明文。
- **数据静态保护**：密码库、密保答案、TOTP 密钥均本地加密，禁明文落盘。
- **内存与界面**：锁定后清除明文、后台禁止明文出现在系统截图/预览。
- **剪贴板**：复制后 30 秒定时清理，降低跨 App 泄露。
- **备份安全**：导出必须口令加密（默认主密码，可另设独立口令）；口令与备份分离。
- **设备风险**：检测到越狱/root 设备时提示风险。
- **日志脱敏**：明文密码、主密码、密保答案不得进入任何日志。
- **高敏操作二次认证**：导出、改主密码、开关生物识别、改密保问题须再次验证主密码。
