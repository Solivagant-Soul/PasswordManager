# V2.1 UI 重做 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修掉实机走查确认的 7 项交互缺陷，并按 `DesignDocument/产品原型图/` 重做整体 UI（主题、公共组件、设置页信息架构、编辑页字段收口）。

**Architecture:** 保持「四个 Tab × 独立回退栈」的手写导航（不引 navigation-compose）。新增 `ui/theme/` 与 `ui/components/` 两个包承载视觉体系与公共组件；各 Screen 改为消费公共组件。领域层与数据层只做最小改动（生成器上限常量、偏好端口扩展），不涉及 Room schema 迁移。

**Tech Stack:** Kotlin 2.0.21 / Compose BOM 2024.12.01 / Material 3 / Hilt 2.52 / DataStore Preferences / Room+SQLCipher（不动）/ Gradle 8.10.2 / JDK 17。

**Spec:** `DesignDocument/V2.1-UI重做设计.md`

## Global Constraints

以下为全项目约束，每个 Task 隐含包含，不再逐条重复：

- **源根只用 `src/{main,test,androidTest}/kotlin`**——历史上 `java/` 与 `kotlin/` 双源根并存会导致 KSP 重复生成注入器（`FileAlreadyExistsException`）。
- **androidTest 禁用反引号方法名**（minSdk 26 → DEX 038 不接受 SimpleName 空格），方法名必须 camelCase。JVM 单测（`src/test`）不受此限。
- **不新增 Gradle 依赖**。特别是禁止引入 `material-icons-extended`——本机网络对 maven.google.com 大文件下载不可达。
- **签名材料不入库**：`*.jks` / `*.keystore` / `credentials.properties` 保持忽略。
- **数据层自持调度器**：Argon2 走 `Dispatchers.Default`、SQLCipher/Room 走 `Dispatchers.IO`，调度器选择留在用例/仓库内部，ViewModel 不得切。
- **不写 Room schema 迁移**：`entries.type` 列保留（决策 D1），本轮只停用其 UI 入口。
- **每完成一个 Task 提交一次本地 git**，不推远程。
- **验证命令**（改动涉及 :domain / :data / :app 时按需裁剪）：
  `./gradlew :app:assembleDebug :app:testDebugUnitTest :data:testDebugUnitTest :domain:test :core:test :platform:testDebugUnitTest :app:lintDebug`

## Review Focus

以下五类输入/条件最容易在实现中被漏掉，各自的测试挂在对应 Task 里：

1. **生成器长度恰好为 32 与恰好为 33** —— 32 必须成功、33 必须返回 `LENGTH_OUT_OF_RANGE`，而滑动条与 `setDefaultPasswordLength` 的上界也必须同步收口到 32（否则用户能存进 33，打开页面时却被夹断）。测试见 Task 2。
2. **生成器选项五个开关全被关掉** —— `charSets()` 返回空集时 `generate` 必须失败而不是抛异常或死循环；编辑页的「⚡生成」按钮在这种情况下要给出可见提示而不是静默无反应。测试见 Task 4。
3. **DataStore 中不存在生成器偏好键（首次安装）** —— 五个开关必须回落到「四类全开 + 排除易混淆」的安全默认，而不是 `booleanPreferencesKey` 默认的 `false`（那会让首次生成出一个纯空字符集）。测试见 Task 4。
4. **收藏切换后立即离开详情页** —— `loadDetail` 是异步的，收藏写盘与详情重载之间存在窗口；锁定时 `applyLocked()` 清 `details` 后，迟到的 `loadDetail` 不得把明文写回。测试见 Task 3。
5. **设置子页栈深为 2 时按返回键** —— 必须回退到设置主页而不是退出 App；锁定清栈后子页不得成为栈底。测试见 Task 7。

```kotlin
package com.zz.passwordmanager.domain.password

/**
 * 密码生成器选项（v2.1/D4）。
 *
 * 提升为**全局偏好**的原因：编辑页的「⚡生成」要零弹窗直填，而生成器页与编辑页
 * 必须用同一套参数——所以这份配置不能是页面内的临时 `remember` 状态，
 * 得经 [com.zz.passwordmanager.domain.preferences.UserPreferences] 落到 DataStore。
 *
 * 全字段默认 `true`：首次安装时 DataStore 里没有这些键，若按 `booleanPreferencesKey`
 * 的天然默认 `false` 回落，用户会拿到一个**空字符集**，生成按钮永远失败。
 */
data class GeneratorOptions(
    val useUpper: Boolean = true,
    val useLower: Boolean = true,
    val useDigit: Boolean = true,
    val useSymbol: Boolean = true,
    val excludeAmbiguous: Boolean = true,
) {
    /** 映射为生成器的字符集；可能为空集（用户把开关都关了），调用方需自行处理。 */
    fun charSets(): Set<PasswordGenerator.CharSet> = buildSet {
        if (useUpper) add(PasswordGenerator.CharSet.UPPER)
        if (useLower) add(PasswordGenerator.CharSet.LOWER)
        if (useDigit) add(PasswordGenerator.CharSet.DIGIT)
        if (useSymbol) add(PasswordGenerator.CharSet.SYMBOL)
    }

    /** 与 [defaultPasswordLength] 组合成完整生成规则。 */
    fun rules(length: Int): PasswordGenerator.Rules =
        PasswordGenerator.Rules(length = length, sets = charSets(), excludeAmbiguous = excludeAmbiguous)
}
```

```kotlin
/** 彩色圆角首字母块（设计稿各列表页统一的头像样式）。同首字母取同色，便于扫读。 */
@Composable
fun Avatar(title: String, size: Dp = 40.dp, modifier: Modifier = Modifier) {
    val accent = accentFor(title)
    Box(
        modifier = modifier
            .size(size)
            .clip(RoundedCornerShape(10.dp))
            .background(accent),
        contentAlignment = Alignment.Center,
    ) {
        Text(
            text = title.firstOrNull()?.uppercase() ?: "?",
            color = Color.White,
            fontWeight = FontWeight.Bold,
        )
    }
}

private val AccentPalette = listOf(
    Color(0xFF5B6ABF), Color(0xFFE0575B), Color(0xFF3BA55C),
    Color(0xFFE08A2E), Color(0xFF9B59B6), Color(0xFF16A085),
)

private fun accentFor(title: String): Color {
    val key = title.firstOrNull()?.code ?: 0
    return AccentPalette[((key % AccentPalette.size) + AccentPalette.size) % AccentPalette.size]
}
```

```kotlin
/**
 * 密码生成器（FR-4/FR-14/T38 + v2.1/F5/D4）。
 *
 * v2.1 变化：
 * - **去掉顶部返回键**——它是 Tab 根页，没有回退语义（F5）。
 * - 选项读写**全局偏好**（DataStore），与编辑页「⚡生成」共用同一份（D4）。
 * - 长度上界 32（Task 2）。
 */
@Composable
fun GeneratorScreen(
    initialLength: Int,
    options: GeneratorOptions,
    onOptionsChange: (GeneratorOptions) -> Unit,
    onCopy: (String) -> Unit,
) {
    var length by remember {
        mutableIntStateOf(initialLength.coerceIn(PasswordGenerator.LENGTH_MIN, PasswordGenerator.LENGTH_MAX))
    }
    var error by remember { mutableStateOf<String?>(null) }
    var password by remember { mutableStateOf("") }

    fun regenerate() {
        if (options.charSets().isEmpty()) {
            error = "请至少选择一种字符集"
            password = ""
            return
        }
        error = null
        PasswordGenerator.generate(options.rules(length)).onSuccess { password = it.concatToString() }
    }

    // 首次进入即生成，避免空白页；选项或长度变化时同步重算
    LaunchedEffect(length, options) { regenerate() }

    Column(
        modifier = Modifier
            .fillMaxSize()
            .verticalScroll(rememberScrollState())
            .padding(horizontal = 16.dp),
    ) {
        PageHeader(title = "密码生成器")
        Spacer(Modifier.height(12.dp))

        Box(
            modifier = Modifier
                .fillMaxWidth()
                .clip(RoundedCornerShape(12.dp))
                .background(MaterialTheme.colorScheme.primaryContainer)
                .padding(16.dp),
            contentAlignment = Alignment.Center,
        ) {
            Text(
                text = password.ifEmpty { "—" },
                fontFamily = FontFamily.Monospace,
                style = MaterialTheme.typography.titleMedium,
                color = MaterialTheme.colorScheme.onPrimaryContainer,
                textAlign = TextAlign.Center,
            )
        }

        val level = remember(password) { PasswordStrength.evaluate(password) }
        Spacer(Modifier.height(12.dp))
        LinearProgressIndicator(progress = { level.fraction }, modifier = Modifier.fillMaxWidth())
        Text(
            text = "强度：${level.label}",
            style = MaterialTheme.typography.bodySmall,
            modifier = Modifier.fillMaxWidth().padding(top = 4.dp),
        )

        Spacer(Modifier.height(16.dp))
        Row(verticalAlignment = Alignment.CenterVertically) {
            Text("长度", modifier = Modifier.weight(1f))
            Text("$length", style = MaterialTheme.typography.titleMedium, color = MaterialTheme.colorScheme.primary)
        }
        Slider(
            value = length.toFloat(),
            onValueChange = { length = it.toInt() },
            valueRange = PasswordGenerator.LENGTH_MIN.toFloat()..PasswordGenerator.LENGTH_MAX.toFloat(),
            steps = PasswordGenerator.LENGTH_MAX - PasswordGenerator.LENGTH_MIN - 1,
            modifier = Modifier.fillMaxWidth(),
        )

        CharSetToggle("大写字母 A-Z", checked = options.useUpper) {
            onOptionsChange(options.copy(useUpper = it))
        }
        CharSetToggle("小写字母 a-z", checked = options.useLower) {
            onOptionsChange(options.copy(useLower = it))
        }
        CharSetToggle("数字 0-9", checked = options.useDigit) {
            onOptionsChange(options.copy(useDigit = it))
        }
        CharSetToggle("符号 !@#\$%^&*", checked = options.useSymbol) {
            onOptionsChange(options.copy(useSymbol = it))
        }
        CharSetToggle("排除易混淆字符", checked = options.excludeAmbiguous) {
            onOptionsChange(options.copy(excludeAmbiguous = it))
        }

        error?.let {
            Text(text = it, color = MaterialTheme.colorScheme.error, modifier = Modifier.padding(top = 4.dp))
        }

        Spacer(Modifier.height(16.dp))
        Row(
            modifier = Modifier.fillMaxWidth(),
            horizontalArrangement = Arrangement.spacedBy(12.dp),
        ) {
            OutlinedButton(onClick = { regenerate() }, modifier = Modifier.weight(1f)) { Text("重新生成") }
            Button(onClick = { onCopy(password) }, enabled = password.isNotEmpty(), modifier = Modifier.weight(1f)) {
                Text("复制密码")
            }
        }
        Spacer(Modifier.height(16.dp))
    }
}

/** 生成器的字符集开关行。 */
@Composable
private fun CharSetToggle(label: String, checked: Boolean, onChange: (Boolean) -> Unit) {
    Row(
        verticalAlignment = Alignment.CenterVertically,
        modifier = Modifier.fillMaxWidth().padding(vertical = 2.dp),
    ) {
        Text(label, modifier = Modifier.weight(1f))
        Switch(checked = checked, onCheckedChange = onChange)
    }
}
```

补 import `androidx.compose.runtime.LaunchedEffect`。

> **为什么用 `LaunchedEffect(length, options)` 而不是原来的 `if (password.isEmpty()) regenerate()`**：原写法在 Composable 体内直接改状态，且选项变化后不会重算。`LaunchedEffect` 以 `length`/`options` 为键，任一变化即重生成，且不会在每次重组时触发。
